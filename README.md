# מחברת המתכונים שלי

אתר מתכונים אישי בסגנון טרטוריה וינטג׳ – נייר קרם, כותרות אדומות, כותרת בכתב יד ואיורי קו ירוקים. מתארח ב-GitHub Pages.

## מבנה

- `index.html` – עמוד הבית: חיפוש, קטגוריות, מתכון אקראי, מועדפים
- `recipe.html?id=...` – עמוד מתכון: מצרכים עם תיבות סימון, אופן הכנה, מסך דולק
- `data/recipes.js` – **כל המתכונים נמצאים כאן**
- `assets/style.css` – העיצוב (דסקטופ ומובייל)
- `assets/app.js` – הקוד של העמודים
- `assets/art.js` – האיורים (SVG). איור הכרטיס נבחר לפי שם המתכון: דג, מחבת, מאפינס, עוגיות או קערת פסטה
- `.nojekyll` – אומר ל-GitHub Pages להגיש את הקבצים כמו שהם

## הוספת מתכון

מעתיקים אובייקט קיים ב-`data/recipes.js` ומשנים את השדות:

| שדה | הסבר |
| --- | --- |
| `id` | מזהה באנגלית, ייחודי (מופיע בכתובת) |
| `title` | שם המתכון |
| `description` | תיאור קצר בשורה אחת שמופיע מתחת לשם בכרטיס (לא חובה) |
| `category` | קטגוריה – לשוניות נוצרות אוטומטית |
| `prepTime`, `cookTime` | זמני הכנה ובישול (טקסט) |
| `totalMinutes` | זמן כולל בדקות (מוצג בכרטיס) |
| `added` | תאריך הוספה `YYYY-MM-DD` (החדש ביותר מקבל תגית "חדש!"; באותו יום – האחרון בקובץ) |
| `source` | קישור למקור ותווית (לא חובה) |
| `ingredients` | קבוצות מצרכים, לכל אחת `title` אופציונלי ו-`items` |
| `steps` | שלבי ההכנה. שלב שמתחיל ב-"טיפ:" מוצג כפתק |

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן, או:

```
python -m http.server 8000
```

## פרסום

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
